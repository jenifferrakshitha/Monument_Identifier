\# Monument Identifier



\## Project Overview

Monument Identifier is an image-based monument identification project.



\## Objective

To identify historical monuments from uploaded images and provide useful information about them.



\## Main Workflow

1\. User uploads a monument image.

2\. The system processes the image.

3\. The model identifies the monument.

4\. The system displays the identification result.
